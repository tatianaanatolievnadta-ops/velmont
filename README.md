# Velmont — архитектура

Сайт сделан Татьяной Желиховской.

## Публикация на GitHub Pages
1. Создайте репозиторий с названием **velmont**.
2. Add file → Upload files → перетащите все файлы этой папки.
3. Settings → Pages → ветка `main`, папка `/ (root)` → Save.
4. Адрес сайта: https://tatianaanatolievnadta-ops.github.io/velmont/

Ссылка кнопки «Сайт сделан Татьяной Желиховской» — в файле `link.js`.
